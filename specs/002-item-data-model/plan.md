# Implementation Plan: Item Data Model Enhancements

**Branch**: `002-item-data-model` | **Date**: 2026-09-17 | **Spec**: [spec.md](spec.md)

## Summary

Add two new fields to the Item entity — `description` (optional free text) and `importance` (integer 0–100, default 50) — and wire them through all layers: data model, operations, CLI tools, dispatcher, and GUI display. No new dependencies. Reuses existing `validate_importance` logic.

**Language/Version**: Python 3.11+

**Primary Dependencies**: anthropic>=0.34, flask>=3.0, pytest>=8.0 (unchanged)

**Storage**: Single JSON file at `~/.todo-agent/todos.json` (unchanged)

**Testing**: pytest

**Target Platform**: macOS local machine

**Project Type**: CLI + local web GUI sharing a single core module

**Performance Goals**: N/A — local single-user tool

**Constraints**: Backward-compatible schema change; existing items without the new fields must load without error

**Scale/Scope**: Additive change to 6 existing files; 2 new operations; 2 new CLI tools
